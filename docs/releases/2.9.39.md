# ELFIS Door Studio 2.9.39

This release brings GitHub up to date with the validated Doors 2.9.39 and optional Handles 1.1.9-beta tools.

## Fronts and ordering
- Five-Piece, One-Piece, Slab and rear-cut J-Pull profiles, drawer variants and nested front replacement.
- Material/tag/machining preservation, Slab edge-band materials and OpenCutList grain workflow.
- Consolidated order window, Facade/Finishing groups, filters, multi-selection, highlight/zoom, clipboard and print-friendly portrait A4 PDF.
- Plinth stock-length planning, expandable cut trees, kerf and shared offcuts across widths.

## Cabinet tools added since 2.9.14
- Shelf-pin rows; 21-spindle/32 mm dowel-and-screw patterns referenced to the source rail/shelf front.
- Hinge cup/front/side drilling with count, offsets, side and viewport controls.
- TANDEMBOX M/D 500 mm reference drilling with front-relative overlays, adoption and refresh. Other drawer patterns/models are not included.
- Kamar hanger cutouts: Left/Right/Both layouts per back, legacy recognition and Alt removal/repair.
- Arrange Shelves: count, visible clear openings, fixed mm/weighted gaps, cloning/removal and support regeneration in one Undo.
- Upright L-corner cabinets: actual shelf outlines and perpendicular contacts, recognized exterior through-back support rows, independent back joints and mirrored hinge sides.
- Existing-drilling adoption/conversion, Refresh drilling with deleted-shelf cleanup, central defaults, configurable panel tags and visibility tools.

## Optional Handles 1.1.9-beta
- Separate Add/Remove/Library toolbar commands, own SKP library and fixing-point calibration.
- Automatic length measurement, expanded position/orientation shortcuts and signed side-pull offset from centre.
- Handle order counts and combined PDF. No manufacturer handle models are bundled.

## Install and validation
Install Doors first, then Handles if needed, through SketchUp Extension Manager. Fully restart SketchUp. Tested in SketchUp Pro 2026 on Windows; 248 passing native Doors checks, including 88 corner checks. Handles remains beta and requires a calibration/fit check. Review every machining operation before production. Older releases remain available.
