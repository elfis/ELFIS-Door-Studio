# ELFIS Door Studio 2.9.25

SketchUp tools for cabinet fronts, handles, CNC vectors and order lists, supporting workflows with Blum Online Configurator, ABF2 and OpenCutList.

Use the existing Hanger Cutouts icon: click to add; **hold Alt and click a back to remove its Kamar L contours and fill both notches**. Red preview indicates removal; releasing Alt resumes adding. No new icon.

Preserves face/component materials, unrelated drilling, other cabinet copies and shared tag definitions. Supports matching legacy loops and one Undo. Earlier versions are preserved.
