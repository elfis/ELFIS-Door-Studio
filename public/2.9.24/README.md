# ELFIS Door Studio 2.9.24

SketchUp tools for cabinet fronts, handles, CNC vectors and order lists, supporting workflows with Blum Online Configurator, ABF2 and OpenCutList.

New toolbar/menu command: **ELFIS — Hanger Cutouts / Wycięcia pod zawieszki**. Click a back or select cabinets/backs.

- Kamar: two top through-notches, 55 mm high × 20 mm wide.
- Closed exterior L contours: 63 × 31 mm, including 8 mm below and 11 mm inwards.
- Group name/standard group tag: Blum Operations. Edge tag: Kamar D6.0_DEPTH_8.0.
- Reuse correct notches and matching legacy loops. No duplicates on repeated application. Preserve unrelated machining/materials and other cabinet copies. One Undo.

Install through Extension Manager. Earlier versions are preserved. Only Kamar is currently available; future hanger types can use additional presets.
