# ELFIS Door Studio 2.9.18

Central defaults panel: shelf pins, dowels and screws, existing drilling, panel tags and visibility-button assignments. No door/profile settings are moved.

Install ELFIS_Profile_Library_2.9.18.rbz through SketchUp Extension Manager, then restart SketchUp. Includes ELFIS Tags 1.03. Open the gear icon on ELFIS — Doors or Extensions → ELFIS — Default settings / Ustawienia domyślne.

Existing drilling: select the cabinet, scan, review associations, select rows, then adopt unchanged or adopt and update diameter/depth. Unsupported and ambiguous groups are skipped. See the English/Polish guides for details.

Tested in SketchUp 2026 on Windows: 22 native checks, EN/PL interface checks, Ruby compilation and PDF-filename regression. Native test fixtures and preferences were rolled back. Previous packages are preserved.

## Polski

Panel ustawień domyślnych jest pod ikoną koła zębatego i w menu Extensions. Tagi można wpisywać po przecinku. Room przełącza grupy nazwane room. Zakładka Istniejące wiercenia pozwala rozpoznać, przejąć i zmienić parametry obsługiwanych grup bez przesunięcia środków otworów. Zapis ustawień sam nie zmienia geometrii.
