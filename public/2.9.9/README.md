# ELFIS Door Studio 2.9.9

New fourth Doors-toolbar icon: Shelf Pin Rows / Podpórki półek. Configure dimensions, then click an adjustable shelf. To process several shelves, select their components inside the cabinet before clicking the icon. Separate vector groups inside both side panels: group tag Blum Operations, circle tag D5.0_DEPTH12.0. Default 12 holes per shelf, centre 2.5 mm below underside, spacing +/-32 mm. Existing matching machining is not duplicated.

Fixed shelves, dowels and screws are deferred. Previous versions are preserved. See docs for supported geometry and settings.
