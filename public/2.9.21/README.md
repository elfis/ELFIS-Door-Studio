# ELFIS Door Studio 2.9.21

ELFIS Door Studio is a SketchUp plugin for creating and replacing cabinet fronts, placing handles, preparing drilling vectors and compiling order lists. It is designed to support workflows with **Blum Online Configurator, ABF2 and OpenCutList**.

**Polski:** Wtyczka do SketchUpa służąca do tworzenia i podmiany frontów meblowych, rozmieszczania uchwytów, przygotowywania wektorów wierceń oraz zestawień zamówień, przeznaczona do współpracy z **Blum Online Configurator, ABF2 i OpenCutList**.

- Back screws respect hanger cutouts. End margins start at the available material boundary, independently on each side.
- Fix startup SyntaxError while reading central visibility/tag settings; recover old values and save them in restart-safe storage.
- Existing features retained; no background auto-refresh added.

Use Update drilling to regenerate existing ELFIS-owned holes. Install through Extension Manager. Previous versions are preserved.
