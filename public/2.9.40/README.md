# ELFIS Door Studio 2.9.40

Default settings → Toolbars: configure Doors, Handles and Visibility order, icons, separators and whole-bar visibility. Drag rows or use arrows, restore one toolbar, save and restart SketchUp. The settings command remains in Extensions.

Existing drilling fixes imported L-corner dowel and screw recognition, including legacy back-screw spacing. Adoption and parameter conversion preserve hole centres. Rescan after updating.

Install through Extension Manager and fully restart SketchUp. Handles 1.1.10-beta is needed for the configurable handle bar. Previous installers are retained. See the included EN/PL guides and validation summary.
