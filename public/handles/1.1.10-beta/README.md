# ELFIS Handles 1.1.10-beta

Support the shared toolbar preferences in Doors 2.9.40: Add, Remove and Library buttons can be reordered/hidden from Default settings → Toolbars. Save and restart SketchUp. With older Doors versions, the standard toolbar remains available. Placement geometry, calibration and keyboard rules are unchanged from 1.1.9-beta. Standard handles remain beta; calibrate and verify the actual model before production.
