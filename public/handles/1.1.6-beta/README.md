# ELFIS Handles 1.1.6-beta

**BETA — Calibrate standard handles before use and check placement on a test front.**

Remove ELFIS handles by clicking front components. Tap Ctrl to switch horizontal top centre / vertical top right; tap Shift for horizontal top/bottom or vertical right/left. Positions stay after key release. Live settings, independent offsets and fixing-point calibration. Edge-pull mounting rules are unchanged.

Requires ELFIS Door Studio 2.9.1. Install the RBZ through SketchUp Extension Manager, then restart SketchUp.

[English guide](../../../ELFIS_Handles_README.en.md) · [Polska instrukcja](../../../ELFIS_Handles_README.md)

## Toolbar

ELFIS — Handle Tools has three buttons: Add Handle, Remove Handle, Handles Library. The library is the same existing HTML window, renamed only. Add/Remove work directly on clicked fronts. Initial placement uses the already-imported Block Key Bar Handle, top right, vertical; later library choices stay saved. Ctrl/Shift placement shortcuts remain available. No private handle model is included in the installer.

1.1.6-beta also separates the new toolbar from the legacy one-button toolbar to prevent duplicate library icons during an update in a running SketchUp session. The old toolbar is hidden. Previous installer versions are preserved.
