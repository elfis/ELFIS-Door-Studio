# ELFIS Handles 1.1.9-beta

**BETA — Calibrate standard handles before use and check placement on a test front.**

Remove ELFIS handles by clicking front components. Tap Ctrl for vertical/horizontal, Shift for left/right, Alt for top/bottom, Tab for corner/edge centre. Positions stay after key release. Live settings, independent offsets and fixing-point calibration. Edge pulls rotate to their selected edge; corner placement uses the end offset. On side-mounted edge pulls, Shift cycles centre/up/down by a configurable distance; Alt switches sides. Existing saved edge layouts remain compatible until explicitly changed.

Requires ELFIS Door Studio 2.9.1. Install the RBZ through SketchUp Extension Manager, then restart SketchUp.
