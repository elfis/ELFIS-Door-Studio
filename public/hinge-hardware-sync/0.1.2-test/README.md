# ELFIS Hinge Hardware Sync 0.1.2 test

Experimental add-on for synchronizing previously calibrated hinge and mounting-plate geometry to drilling in ELFIS Door Studio. Install the code-only RBZ in SketchUp Extension Manager and restart. For a new setup, start with a cabinet that already has correctly placed hardware and matching drilling, then use the ELFIS command to link them. Supply your own SketchUp hardware models. The archive contains the Ruby code and ships with an empty template library. SketchUp runtime tests were not rerun for this package.
