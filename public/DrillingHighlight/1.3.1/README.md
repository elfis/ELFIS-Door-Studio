# ELFIS Drilling, Edge & Tag Highlight 1.3.1

Standalone SketchUp overlay for drilling circles, edge banding and selected tags. Install the RBZ in SketchUp Extension Manager and restart SketchUp. See the [1.3.0 user guide](../1.3.0/ELFIS_Drilling_Highlight_README.md) for controls and OpenCutList material recognition. The 1.3.1 archive was assembled from local sources and checked for the required Ruby, HTML and SVG files. SketchUp runtime tests were not rerun for this publication.
