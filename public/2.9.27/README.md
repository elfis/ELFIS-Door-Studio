# ELFIS Door Studio 2.9.27

New hinge drilling toolbar icon. Click an upright front to add Ø35 + 2 × Ø8 front circles and paired Ø5 × 11.5 side holes. Alt removes associated drilling, Ctrl regenerates it. Right-click opens count, side, offsets and depth settings. Default pattern matches the supplied Blum TOP cabinet. Does not insert or animate hardware. Unassociated imported drilling is preserved.

SketchUp workflows with Blum Online Configurator, ABF2 and OpenCutList. Earlier versions are preserved. See docs for dimensions and limitations.
