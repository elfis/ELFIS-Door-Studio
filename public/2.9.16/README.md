# ELFIS Door Studio 2.9.16

New **Dowels and Screws / Kołki i śruby** toolbar icon. Creates side-panel vector groups from clicked/selected rails, fixed shelves and backs. Rails follow the inspected 32 mm / 21-spindle layout; short top rails crop the same datum. Back panels use screws only, equally spaced. The confirmed 0.2 mm axis correction is retained.

Defaults: dowel Ø8 × 14 mm, screw Ø3 × 18 mm, first spindle 30 mm from the side front; source and side panels on Body, back on Back Wall. Each hole is its own named group on Blum Operations with diameter/depth tags on its circle edges. Imported holes and shelf supports are preserved. No rail/shelf edge drilling or solid subtraction. Right-click the active tool for settings; Esc ends it; Ctrl+Z undoes one application. Selecting a cabinet excludes adjustable shelves from the structural batch. A back panel establishes front/rear orientation.

75 native SketchUp 2026 checks, live settings/preview/toolbar checks, 13 standalone Ruby layout checks and EN/PL HTML tests passed. Previous versions are preserved. Install with Extension Manager and restart SketchUp after saving, or restart after the installed file update. See included bilingual documentation and VALIDATION.json.
