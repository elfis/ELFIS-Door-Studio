# ELFIS Door Studio 2.9.23

SketchUp tools for cabinet fronts, handles, drilling vectors and order lists, supporting workflows with Blum Online Configurator, ABF2 and OpenCutList.

- Add exterior screw rows in backs at actual bottom/top rails, with inward axis correction (9.2 mm for an 18 mm rail and 0.2 mm correction).
- Omit missing rails and front-only stretchers. Remove obsolete rows on reapplication.
- Include rear screws in scan/adoption, parameter editing, removal and refresh.
- Adding/removing on a selected cabinet continues in click mode without manual deselection.

Installed files in SketchUp 2026 are updated. Earlier versions are preserved.
