# ELFIS Door Studio 2.9.14

Includes 2.9.13 order-list groups, size sorting, Escape clearing and portrait A4 PDF.

Plinth widths share stock-length offcuts by default: parts 79 and 150 mm are packed together from stock at the widest required width. Enable Separate stock widths (79 / 150 mm) for independent layouts. Materials, colours, products, suppliers and board thicknesses remain separate. Tree/clipboard/PDF retain each part's length and width. This is one-dimensional cutting, not 2D nesting or joining short remnants.

Calculation and PDF tests run in standalone Ruby 3.2.4, plus EN/PL headless browser tests. Live SketchUp validation of this follow-up is pending: the user requested no UI control. Previous version 2.9.13 was tested in SketchUp 2026 and remains available.

Install through Extension Manager and restart SketchUp after saving your work. No user model, personal library or private project PDF is included.
