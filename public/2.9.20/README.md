# ELFIS Door Studio 2.9.20

- Update drilling toolbar command: remove old owned holes and regenerate at the moved shelf/rail/back in one Undo operation. Supports clicking and selection; no background auto-refresh.
- Multiple complete circles in imported vector containers are recognized separately, including bottom dowels and screws. Adopt imported drilling before moving its source.
- Back screw axes follow the actual thickness centre, including recessed backs.

Install through SketchUp Extension Manager and restart. The local SketchUp 2026 installation is already updated. Previous versions are preserved. English/Polish guides are in docs.
