# ELFIS Door Studio 2.9.26

SketchUp tools for cabinet fronts, handles, CNC vectors and order lists, supporting workflows with Blum Online Configurator, ABF2 and OpenCutList.

In Shelf Pin Rows and Dowels and Screws: **click adds, hold Alt + click removes, hold Ctrl + click refreshes drilling after a panel has moved**. Release to return. Red removal / green refresh preview. Ctrl does not move the panel itself. Imported drilling must first be adopted. No new toolbar icon or background auto-refresh. Earlier removal/refresh icons remain available.

Includes one-Undo updates, per-tool refresh for dual-owned panels, and existing Kamar Alt removal. Earlier versions are preserved.
