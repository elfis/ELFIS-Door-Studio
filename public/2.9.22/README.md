# ELFIS Door Studio 2.9.22

SketchUp tools for cabinet fronts, handles, drilling vectors and order lists, supporting workflows with Blum Online Configurator, ABF2 and OpenCutList.

Room defaults to tags: Windows, Walls, Skirting Boards, Room Doors, Floor Plan, Floor, Ceiling. Saved custom assignments remain unchanged. Choose Restore defaults in ELFIS settings to reset assignments.

Changes are installed in SketchUp 2026; restart to load the new code. Previous versions are preserved.
