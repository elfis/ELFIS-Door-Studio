# ELFIS Door Studio 2.9.13

- Escape clears order-list and model highlights.
- Numeric size sorting and Finishing product subgroups.
- Portrait A4 PDF; bold quantity before dimensions.
- Whole-stock plinth orders (default 2400 mm, 3 mm kerf), expandable cutting trees and exact occurrence highlights.

Install the RBZ through Extension Manager, then restart SketchUp. Previous release folders and a full pre-change source backup are retained.

Plinth stock products are identified by tag (or explicit stock_product metadata). Different products/tags, suppliers, colours and cross-sections are calculated separately. Stock length and kerf are editable. No end-trim or mitre allowance is included. Oversize parts are flagged. For larger/difficult orders a bounded optimiser may report an approximate layout.

Lista zamówienia: Escape usuwa podświetlenie, wymiary można sortować, a Finishing ma podgrupy produktów. PDF jest pionowy A4 z pogrubioną ilością przed wymiarami. Cokoły są przeliczane na pełne listwy z rozwijanymi częściami.

See docs/CHANGELOG.md and the English/Polish user guides for details. This release does not add door/drawer animation or Plinth Maker geometry.
